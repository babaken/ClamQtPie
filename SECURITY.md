# セキュリティポリシー / Security Policy

## 対応している版 / Supported versions

最新のリリースだけを対象に、セキュリティの修正を行います。
Security fixes are provided for the latest release only.

## 脆弱性の報告 / Reporting a vulnerability

脆弱性を見つけた場合は、公開の Issue には書かず、GitHub の非公開の報告機能で知らせてください。

1. このリポジトリの **Security** タブを開く
2. **Report a vulnerability** から報告する

Please do not open a public issue. Use GitHub's private vulnerability reporting instead:
open the **Security** tab of this repository and choose **Report a vulnerability**.

報告には、影響する版、再現の手順、想定される影響を書いてください。
Please include the affected version, steps to reproduce, and the expected impact.

## 対応の流れ / What to expect

- 受け付けたことを、できるだけ 7 日以内に返信します（個人で開発しているため、目安です）。
- 修正版を公開するまで、内容は公開しないようお願いします。修正版の公開後に、必要に応じて GitHub Security Advisory で告知します。

- We aim to acknowledge reports within 7 days (best effort; this is a personal project).
- Please keep the details private until a fixed release is published. After the release, we may publish a GitHub Security Advisory.
